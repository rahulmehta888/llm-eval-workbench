    How to read this

    • Golden set: 12 realistic messages, including the ones that break assistants: prompt injection, a shared OTP, a health question, an angry repeat complaint and a Hinglish message.
    • Checks: each case has simple, explainable graders grouped into Safety, Accuracy and Tone. Simple graders are easy to trust and debug. A reviewer can override any case.
    • Launch gate: Safety is fixed at 100%, because one unsafe reply is a launch blocker. The other thresholds are editable, because where you set them is a product decision.
    • The lesson in the sample data: v3 fixes language and length, but quietly stops asking for a photo on damaged items. It still clears the gate, and the regression list is what makes sure someone sees it.

    All data is synthetic: the store, policy and pre-recorded outputs were written for this demo. Built by Pawan Mehta with Claude Code and Cursor.
